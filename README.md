# 📒 Contact Book

A simple Python-based Contact Book application that helps users manage contacts efficiently using a menu-driven interface. The project stores contact details permanently in a JSON file.

---

# 🚀 Features

✅ Add New Contact  
✅ View Contact List  
✅ Search Contact by Name or Phone Number  
✅ Update Contact Details  
✅ Delete Contact  
✅ Permanent Data Storage using JSON  
✅ User-Friendly Command Line Interface  

---

# 📝 Contact Information Stored

Each contact contains:

- Name
- Phone Number
- Email Address
- Address

---

# 🛠️ Technologies Used

- Python 3
- JSON File Handling
- File Management
